# ColumbiaWalks 3.14.1

This clarity release keeps the 3.14 reporting workflow while making the interface consistent across phones:

- keeps every app screen on the intended pale background, including when the phone uses Dark Mode;
- uses explicit high-contrast colors for primary text, instructions, validation messages, and status text;
- separates long guidance from comment and description fields so instructions do not appear doubled or overlap;
- gives scrolling forms and saved-report lists the same pale surface; and
- assigns the distinct version/build identity `3.14.1 (31401)` so it cannot be confused with either 3.14.0 build.

The review and privacy materials also state explicitly that ColumbiaWalks is
independently operated and does not share submissions or user information with
any government agency.

The existing 3.14.0 sources and artifacts remain unchanged.
