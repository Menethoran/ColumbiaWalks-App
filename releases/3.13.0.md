## ColumbiaWalks for Android 3.13.0

This release establishes the permanent ColumbiaWalks production signing identity and adds secure in-app update checks.

### Important upgrade note

Versions through 3.12.0 used temporary debug certificates. Android cannot update across different signing identities, so users of an earlier version must let queued reports finish submitting, uninstall the old app once, and then install 3.13.0. Reports stored only on the phone are removed by an uninstall.

After 3.13.0 is installed, future releases signed by the permanent key can update it in place.

### Update system

- Checks this repository's latest production release when the app launches.
- Downloads only over HTTPS.
- Verifies the release asset size and GitHub SHA-256 digest.
- Verifies the APK package, newer version code, and signing certificate.
- Opens Android's normal user-confirmed installer; it never installs silently.
- Reports anonymous update event totals without device identifiers, contact information, or location.
