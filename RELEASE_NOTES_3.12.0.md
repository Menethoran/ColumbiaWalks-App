# ColumbiaWalks 3.12.0

Released August 14, 2026.

## Page of Shame reporting

- Adds a dedicated PoS tab that opens the camera for a picture-first report.
- Requires the phone's current GPS coordinates with every PoS picture.
- After the picture is accepted, choose **No** to submit the picture and GPS immediately or **Yes** to add an optional description first.
- Keeps submitted material private until it is reviewed for publication.

## Web service

- Adds the same PoS workflow to the Report page on ColumbiaWalks.com.
- Moves the public Page of Shame gallery to its own page.
- Web maintenance release 3.12.1 removes the GPS requirement from website PoS reports; the Android app still requires GPS.
- Web maintenance release 3.12.2 prepares supported phone pictures as compatible JPEG files and shows a clear message for unreadable formats.

## Important Android installation help

Uninstall the old ColumbiaWalks Android app before installing 3.12.0. First make sure any locally saved reports have finished submitting; uninstalling removes reports that exist only on the phone.
